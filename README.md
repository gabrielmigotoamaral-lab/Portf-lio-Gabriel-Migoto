# 💼 Portfólio - Gabriel Migoto Amaral

Portfólio pessoal responsivo desenvolvido com **HTML5**, **CSS3** e **JavaScript**, apresentando minha trajetória acadêmica na **UNITAU (Engenharia da Computação)**, habilidades, projetos e formas de contato.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Layout moderno, variáveis CSS, animações suaves (`fade-in`), flexbox e grid responsivos.
- **JavaScript (ES6+)**:
  - Efeito máquina de escrever (*typewriter*).
  - Animação de entrada dos elementos via `IntersectionObserver`.
  - Destaque automático de menu de navegação de acordo com a rolagem da página.
  - Cópia interativa de e-mail para a área de transferência com feedback visual.
- **Font Awesome**: Ícones para redes e tecnologias.
- **Google Fonts**: Tipografia moderna com *Montserrat* e *Roboto*.
